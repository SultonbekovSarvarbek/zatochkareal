# Zatochka bot

Telegram-бот для приёма заказов на заточку ножей (Узбекистан). Клиент в личке проходит шаги: язык (ru/uz) → имя → телефон → локация → количество ножей → фото. Заказ сохраняется в SQLite и отправляется в группу админов.

## Запуск

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env   # заполнить BOT_TOKEN, GROUP_CHAT_ID, ADMIN_USER_IDS
npm start
```

## Тесты

```bash
npm test
```

Тесты не ходят в Telegram: API подменяется заглушкой, база создаётся в памяти.

## Команды

Клиент (только в личке):
- `/start` — новый заказ
- `/cancel` — сбросить незаконченный заказ

Админы (только в группе `GROUP_CHAT_ID`, только пользователи из `ADMIN_USER_IDS`, если список задан):
- `/find 123` — найти активный заказ по номеру
- `/orders` — список активных заказов
- кнопка «✅ Заказ готов» под заказом

## Данные

Всё хранится в `orders.db` (SQLite, WAL). Для бэкапа остановите бота и скопируйте `orders.db*`.
